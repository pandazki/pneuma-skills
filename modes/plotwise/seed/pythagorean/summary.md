# 勾股定理 · 课程回顾

你走过的路径:**开场** → **3-4-5 亲手验证** → **面积拼图证明**。

- 直角三角形三边满足 a² + b² = c²——两条直角边的平方和等于斜边的平方。
- 你选择了先用例子落地:3² + 4² = 9 + 16 = 25 = 5²,数字亲手算过。
- 证明用的是面积重排:边长 (a+b) 的大正方形里放进四个全等直角三角形,
  中间剩下的空白恰是一个边长为 c 的正方形——空白面积不随摆放改变,
  所以 a² + b² = c² 对一切直角三角形成立。
- 未走的支线:「先打个比方」(面积类比版本)仍在树上,随时可以生成。
