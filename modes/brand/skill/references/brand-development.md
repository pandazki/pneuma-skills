# Develop a brand people can apply

Begin with who the brand is for, the change it promises, its personality, and the
contexts in which it will be encountered. Ask which materials already exist and
which are fixed. A visual language should express that intent across contexts.

Define the identity through concrete rules and examples:

- Mark: primary lockup, alternate arrangements, monochrome and reverse treatment,
  clear space, minimum size and incorrect usage.
- Type: role-based hierarchy, local-script coverage, spacing and actual font sources.
- Color: role, relative usage, backgrounds and contrast-sensitive combinations.
- Graphic language: geometry, texture, icon character, image cropping and rhythm.
- Character, when appropriate: proportions, distinctive features, turnarounds,
  expression range, poses, props and what must remain recognizable.
- Voice: how a headline, encouragement or error sounds in this brand.

Choose representative applications for the stated use scenes. A packaging mockup
tests hierarchy, scale and materials; it does not define a manufactured dieline.
A mobile screen tests density, color roles and character restraint; it does not
promise an implemented app. A social campaign tests recognition at a glance;
it does not require generating every placement size.

For every example, explain the rule it demonstrates, which assets it reuses, what
changes with the context, and what the downstream maker must still resolve.
Examples should reveal the system's range while retaining a recognizable identity.

Review for continuity rather than uniformity. Character shape, material, lighting
and facial logic should persist across poses; changing the entire look between
examples does not demonstrate flexibility. Small typography and legal copy need
editable source and later verification even when the image looks convincing.
