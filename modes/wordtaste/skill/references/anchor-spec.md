# Human reference notes

Human text is the only reference outside aligned-model output distributions,
but its value in this workflow has not yet passed an ablation. Use it as an
optional cold-start aid, not doctrine.

## Collect

- Use lawful, attributable material suitable for analysis.
- Match language, genre, audience, and publication setting.
- Prefer several authors over one personality unless the user explicitly wants
  a single-author voice floor.
- Keep source text private when licensing or user privacy requires it.

## Abstract

Extract texture, not content:

- sentence breathing and interruption;
- paragraph movement;
- how qualifications are carried;
- how examples enter and leave;
- where emphasis lands;
- what kinds of figurative language are absent or sparse.

Do not copy distinctive phrases. Store short notes under
`taste/anchors/<content-type>/`.

## Use

Inject notes as positive reference material. Never turn them into a long ban
list. If the anchor makes the prose more colloquial but less precise, preserve
precision and discard that effect.
