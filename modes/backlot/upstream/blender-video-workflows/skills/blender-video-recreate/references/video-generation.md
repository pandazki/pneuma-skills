# 白模到视频模型

## 输入与能力匹配
读取当前可用视频工具的说明，核实其视频参考、首尾帧、时长、画幅、文件大小与分辨率能力；不根据模型名称猜测支持情况。
优先选择支持视频参考或运动控制的已授权模型，将白模视频作为动作与镜头条件。仅支持图片时导出关键帧并明确这是弱约束，不能保证完整动作复刻。没有可用服务或缺少凭据时完成白模与提示词包，明确最终视频尚未生成。
用户已要求生成且已有服务授权/额度范围时直接执行。若需新付费、新账号、超预算或将本地参考素材上传到尚未明确的服务，先说明具体服务、素材与费用并取得所需授权。提交一次任务后保存任务 ID；超时先查询原任务，不能直接重复扣费提交。

## 提示词包
输出 prompts.md：
- 目标外观：主体身份、服装、场景材质、色彩、氛围。保留白模中的空间布局和行为。
- 动作时间线：以秒写出入场、行走、停止、抬手、触发、亮起与结尾；按实际分镜改写。
- 镜头约束：画幅、机位、运动方向、速度、连续性与结束状态。
- 结构约束：保持人物数量、设备位置、肢体完整、动作先后和接触关系；避免新增镜头、人物或跳切。
- 负面约束：适配服务是否支持单独 negative prompt，不把不支持的参数当成 API 字段。

示例：使用上传白模作为空间布局、人物运动和镜头轨迹参考。将白色科研人员转为穿浅色实验服的真实科研人员，将设备表现为简洁科幻装置。保留原时间线，人物站稳后抬手触碰控制面板，中央装置随后缓慢发蓝光。镜头平滑前推并在末尾停稳，保持单一连续镜头，不增加人物或肢体。具体时间点以交付的镜头表为准。

## 结果
下载或保留工具返回的可访问成品，核实实际尺寸、时长及动作顺序。原生不支持 1080p 时明确原始规格，只有实际完成放大才标注交付为 1080p；不能称其为原生 1080p。
将生成结果与白模逐段对比。模型可能改变步态、接触和镜头，不能保证逐帧锁定。只有在预算允许且有具体修复方向时重试，默认最多追加一次；否则报告偏差并保留白模和任务 ID。
分别链接白模 MP4、可编辑 Blender 文件、提示词和最终模型视频；区分“已生成”“仅准备输入”“待授权/工具不可用”。
