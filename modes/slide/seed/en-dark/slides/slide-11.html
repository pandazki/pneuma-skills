Start

Open a terminal. Start a deck.

$bunx pneuma-skills slide --workspace ./my-first-deck
Needs

Bun 1.3.14+ and one agent CLI: Claude Code, Codex or Kimi Code.

Or the app

Desktop builds for macOS, Windows and Linux bundle Bun for you.

For images

Add an OpenRouter API key to turn on illustration generation.

Then describe the talk you need. This deck started that way.
