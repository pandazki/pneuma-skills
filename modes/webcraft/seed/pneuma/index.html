Both of you work on the same files.

The agent reads and writes the workspace with the tools it already has. A domain viewer shows those files to people as they change, so they can watch and join in.

  1. The agent edits files

    Read, write, edit: the file tools it already uses.

  2. The workspace holds the work

    Everything lives in the directory you pass with --workspace.

  3. The viewer renders it live

    A deck, a document, a board, a diagram, a video, updated with each change.

  4. You join in

    Watch the work, point at what should change, or step in yourself.

See the whole loop

Four pillars hold it up.

  • Visual environment

    Domain viewers turn the workspace into something people can see and point at, updated in real time while the agent works.

  • Skills

    Skills give the agent the know-how of a domain. It keeps working with its native file tools.

  • Continuous learning

    Sessions build on each other: what is learned while working with you carries forward.

  • Distribution

    One command starts a mode in any directory. The source is on GitHub.

Pick a mode.

A mode pairs a viewer with the skill for one domain. Its name goes where the command says <mode>.

  • slide

    HTML presentations with presenter mode and PDF export.

  • doc

    Markdown documents with a live rendered preview.

  • webcraft

    Web pages with a responsive live preview and design commands.

  • diagram

    draw.io diagrams: flowcharts, architecture, UML.

  • draw

    Sketches and visual thinking on an Excalidraw canvas.

  • kami

    Typesetting on a fixed paper size, exported to PDF.

  • remotion

    Code-driven video with a frame-exact live preview.

  • clipcraft

    Video production with tracks, clips and generated media.

Or try another: a website in a new folder.

$bunx pneuma-skills webcraft --workspace ./my-site

More modes open from the launcher, and mode-maker builds your own.

Start with one directory.

$bunx pneuma-skills <mode> --workspace <dir>

Swap <mode> for the domain you are working in and <dir> for the folder to work in.
