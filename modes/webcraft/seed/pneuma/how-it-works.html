Files in the middle.

An agent and a person work on the same directory. The agent edits it with its native file tools. A domain viewer shows it live, and the person watches and joins in.

The loop

Black arrows follow one change in order. The orange path closes the loop. Read top to bottom: each part hands the change to the next, and your turn starts the loop again.

One session, start to finish.

  1. Start a mode in a directory

    Pick the domain you are working in and the folder to work on.

    bunx pneuma-skills <mode> --workspace <dir>

  2. The agent works in files

    It reads, writes, and edits the workspace with the file tools it already has. Skills bring the know-how of the domain.

    Read · Write · Edit

  3. The viewer renders them live

    Changes show up in the domain viewer as they land: a document, slides, a board, a diagram, a video, and more.

  4. You watch and join in

    Watch the work as it happens. Point at what should change, or step in and change it yourself.

  5. The next session builds on this one

    Continuous learning: what is learned while working with you carries forward.

One command, four parts.

bunx

RunnerRuns the package with Bun.

pneuma-skills

PackagePneuma Skills. Source at github.com/pandazki/pneuma-skills.

<mode>

ModeThe domain you are working in.

--workspace <dir>

WorkspaceThe folder you and the agent work in.

$bunx pneuma-skills <mode> --workspace <dir>

Point it at a folder.

$bunx pneuma-skills slide --workspace ./my-deck

Starts a slide deck in ./my-deck. Swap slide for the mode you need and ./my-deck for your folder.
